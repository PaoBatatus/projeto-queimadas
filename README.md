
# Projeto Queimadas

Análise de focos de queimadas e incêndios com dados do Programa Queimadas do INPE.

## Estrutura

- `data/bronze`: dados originais
- `data/silver`: dados tratados
- `data/gold`: dados preparados para análise
- `notebooks`: notebooks do projeto
- `src`: scripts de coleta e tratamento
- `docs`: dicionário e metadados
- `reports`: relatório final
